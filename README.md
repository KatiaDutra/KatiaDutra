## Projetos de BI e dados

### [Painel de Vendas, Margem e Positivação](https://github.com/KatiaDutra/bi_vendas_sr)
Solução de BI construída do zero para uma empresa do comércio, com histórico de janeiro/2020 a julho/2026.

- ETL no Power Query consolidando **158 relatórios** do ERP
- Anonimização em lote com Python para cumprir a **LGPD**
- Modelo **Star Schema**, medidas em DAX, Curva ABC e comparativos YoY e MoM
- Dashboard de 4 páginas: visão geral, lucratividade, positivação por canal e análise temporal

`Power BI` `DAX` `Power Query` `Python` `Pandas`

### [BI para separação financeira PF x PJ em microempresas](https://github.com/KatiaDutra/bi_financeiro_sr) 
Estudo de caso com uma microempresa real para validar 3 painéis: separação PF x PJ, pró-labore seguro e margem real por produto.

`Python` `Pandas` `Excel` `Power Query` `Power BI`
